# 《最后的谢幕》梦核版 · 单元内容整理（Unity 视角）

来源：`最后的谢幕-Yoroll工作台.html`（输入包 01 第 5–8 节）。本文只整理各单元的具体内容和 Unity 需要实现的部分；视频生成提示词见原文件 Part 02。

## 通用约定

- **三层画面**：梦界（粉彩过曝、柔焦）、被拐前（暖粉过曝、颗粒细）、被拐后（褪色偏冷、噪点重）、现实层（纯白过曝，只有光和手）。
- **显影**：UI 快门按钮，同一机位同一构图切换梦界 ↔ 实景界（暖 / 冷），每次播轻快门声。部分线索只在实景界可见。
- **二合解谜**：「前」一件 +「后」一件拖进两个空槽。成功 → 播 6 秒现实层短片 + 一条守则被划掉 + 信任值 +1；失败 → 两件弹回原位，无任何文字。
- **失败原则**：CHOICE、QTE 失败只重置本段或本单元，不死亡、不提示「你选错了」。
- **文字**：画面内不出现任何文字，全部由 UI 叠加。
- **《表演守则》**（每关入口同一张纸，笔迹逐关变化）：一、不许说话。二、哭要笑。三、不许回头。四、谢幕前不许叫真名。五、不按规则演就会被打。
- **伏笔编号**：F1 票根 47 / 病房 47 床｜F2 空座位＋病号服｜F3 镜中慢半拍｜F4 铃铛帽淡影｜F5 画面外那只手｜F6 三个圆少一个｜F7 广播口误「第 47 天观察」｜F8 无指针的钟、灯泡长在地板、走廊无限重复｜F9 快门声（玩家还没有相机）。
