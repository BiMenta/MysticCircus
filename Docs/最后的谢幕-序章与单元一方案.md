# 《最后的谢幕》序章与单元一 · 实现方案

本文把序章《入场券》和单元一《镜子间》细化到可以直接开工的程度：流程、规则、交互、表现、`story.json` 配置、需要新增的代码和资源、验收标准。剧本原文见 [最后的谢幕-单元内容.md](最后的谢幕-单元内容.md)，底层接口见 [FOUNDATION.md](FOUNDATION.md)。

标注 **【建议】** 的是剧本没写死、由我先定下的方案，可以改；标注 **【待定】** 的需要策划拍板。

---

## 0. 总体做法

| 内容 | 实现方式 | 理由 |
|---|---|---|
| 序章 OP-1 ~ OP-5 | AI 视频，剪成一条 44 秒短片 | 纯观看段，无交互 |
| 序章 44–90 秒（黑场、字幕、标题、选择） | Unity UI 叠加 | 剧本要求画面内无文字；文字要能切中英文 |
| 单元一玩法（摆玩具、显影、拾取、二合） | Unity 实时 3D，第一人称 | 需要判定和状态，视频做不了 |
| 单元一回忆画面（1-3、1-4） | AI 视频，**贴在中央镜面上播放** | 天然满足「同一机位同一构图」，玩家不用锁视角 |
| 单元一二合短片（1-5） | AI 视频，关卡内全屏播放 | 6 秒过场 |
| 1-1、1-6 | 可选：作为进场 / 离场镜头；同时作为实时场景的美术参照 | 实时场景做得够好可以不用 |

**画面分层**：项目用的是内置渲染管线（没有 URP），**【建议】** 不迁移管线，写一个全屏调色效果（`OnRenderImage`）来做梦界 / 暖 / 冷 / 白四套色调，避免黑客松期间迁移出问题。

## 1. 序章《入场券》

### 1.1 流程

```
游戏首次启动（无存档）
  └→ 直接播放序章，不进标题页、不显示「按任意键」
      ├ 0–44s   视频 film_prologue（OP-1~OP-5 合成一条）
      ├ 44–46s  黑场静音
      ├ 46–52s  字幕「你醒了。」逐字浮现
      ├ 52–~80s 标题《最后的谢幕》淡入，「第 47 场 / 第 47 天」叠印错位
      └ ~80–90s 选择：走向镜子 / 走向幕布 → 进入单元一
```

- 前 40 秒**不显示任何 UI**，包括 `FilmPlayer` 的跳过提示。
- **【建议】** 第一次游玩不允许跳过序章；看过一次后（跨周目记录）允许按空格跳过。
- 有存档时启动进标题页（标题页另做），「再来一次」从序章重新开始。

### 1.2 视频剪辑要求（交给视频同学）

把 OP-1 ~ OP-5 按顺序拼成 `film_prologue.mp4`（8+8+10+10+8 = 44 秒），**声音在剪辑时混好**，Unity 不再逐秒触发音效：

| 时间 | 声音 |
|---|---|
| 0–3s | 手风琴三拍子（隔壁房间感：低通 + 混响）、老式电流嗡鸣 |
| 6–8s | 手风琴停半拍，插一次心电监护滴声 |
| 8–16s | 纸张摩擦；**第 16 秒一次很轻的快门声** |
| 16–26s | 手风琴停半拍，心电滴声；布料般的安静 |
| 26–36s | 老式喇叭底噪 + 广播女声：「欢迎观看第 47 场演……第 47 天观察。请观众对号入座。」（后半句被电流盖住） |
| 36–44s | 布料声，手风琴重新起拍 |

剪辑完成后按 [CONTENT_GUIDE.md](CONTENT_GUIDE.md) 的 ffmpeg 命令转码。OP-1 的**首帧单独导出一张 PNG**，ED-2 要复用它做无缝衔接。

### 1.3 Unity 叠加层时间轴（44–90 秒）

视频播完后停在黑场，由 Unity 接手：

| 时间 | 表现 | 实现 |
|---|---|---|
| 44.0–46.0 | 纯黑、静音 | 黑色全屏遮罩 |
| 46.0–52.0 | 「你醒了。」逐字浮现，每字约 0.5 秒，打完停留 | 打字机效果，无打字音 |
| 52.0–55.0 | 字幕淡出 | — |
| 55.0–62.0 | 标题《最后的谢幕》缓慢淡入（≥ 3 秒） | 中文衬线字体，居中 |
| 58.0–70.0 | 标题下方「第 47 场」与「第 47 天」**两行叠在同一位置**，透明度各 60%，水平错开 2–4 像素，缓慢漂移 | 两个文本对象，偏移做正弦抖动，幅度很小 |
| 70.0–78.0 | 标题与数字淡出 | — |
| 78.0– | 两个选项出现：「走向镜子」「走向幕布」；无问题文字、无倒计时 | 选项按钮，鼠标或 1/2 键 |

背景声：44 秒后保持静音，选项出现时手风琴在极远处再起。

### 1.4 选择的结果

两条都进单元一，不惩罚、不提示。**【建议】** 剧本「只换一句字幕」改成**换出生点**，更符合「画面内无字」：

| 选项 | 记录 | 进入单元一时 |
|---|---|---|
| 走向镜子 | `setFlag: prologue_mirror` | 出生在镜子间正门，正对三面镜 |
| 走向幕布 | `setFlag: prologue_curtain` | 从侧面一道淡粉幕布后走出，先看到墙上守则 |

**【待定】** 如果坚持换字幕，需要策划给出两句字幕原文和出现时机。

### 1.5 `story.json` 配置

现有 `film` 节点支持视频、字幕、选项，但**不支持打字机、标题叠印和隐藏跳过提示**，需要给 `film` 节点加 `overlays` 字段（见第 3 节新增代码）：

```json
{
  "id": "film_prologue",
  "type": "film",
  "video": "film_prologue.mp4",
  "unskippable": true,
  "hideChrome": true,
  "tailSeconds": 34,
  "overlays": [
    { "at": 46, "until": 55, "kind": "typewriter", "zh": "你醒了。", "en": "You're awake." },
    { "at": 55, "until": 78, "kind": "title", "zh": "最后的谢幕", "en": "The Last Curtain Call" },
    { "at": 58, "until": 78, "kind": "doubled", "zh": "第 47 场|第 47 天", "en": "Show No. 47|Day 47" }
  ],
  "choices": [
    { "zh": "走向镜子", "en": "Walk to the mirror",  "next": "level_u1_mirror", "setFlag": "prologue_mirror" },
    { "zh": "走向幕布", "en": "Walk to the curtain", "next": "level_u1_mirror", "setFlag": "prologue_curtain" }
  ],
  "choiceSeconds": 0
}
```

`at` / `until` 从视频开头算起；`tailSeconds` 表示视频结束后继续保持黑场多少秒，用于放叠加层。

### 1.6 序章验收

- [ ] 首次启动直接进序章，前 40 秒画面上没有任何 UI 元素
- [ ] 第 16 秒能听到快门声，26–36 秒广播口误完整
- [ ] 「你醒了。」逐字出现；标题和两行 47 叠印错位可辨认
- [ ] 两个选项都能进单元一，且出生点不同
- [ ] 中英文切换后叠加层文字跟着切换
- [ ] 读档后不会重放序章（存档节点在单元一）

## 2. 单元一《镜子间》

### 2.1 场景布局

```
                 [中央镜 M1]
      [左镜 M0]                 [右镜 M2]
           \                       /
            \   P0     P1     P2  /     ← 三个等高平台（从正门看左→右）
             \                   /
   玩具 T0（M0 旁）  玩具 T1（M1 旁）  玩具 T2（M2 旁）

   [守则]                         [隐藏隔间（P1 下方）]
                 [正门 / 出生点]
   [侧幕布出生点]
```

- 房间为六边形，**三面主镜**可互动，其余墙面挂 3–5 面装饰镜，角度各异，只反射不互动。
- 平台高度一致、外观一致，靠位置区分。
- **【建议】** 三件玩具：发条小木马（呼应 OP-1 的悬空木马）、铁皮小鼓、布偶兔。每件外形差异要大，远看也能分清。
- 出口门在正门对面，初始锁住（`RequiresSolved`）。
- 梦核要求：粉彩过曝、柔焦、空荡对称；至少放一处「错位」：例如灯泡串长在地板沿墙根排列（F8）。

### 2.2 单元流程

```
进入（出生点按序章选择）
  ↓
阶段 A  自由观察：守则、镜子、玩具、镜框划痕（不对的细节）
  ↓   第一次走近任一主镜，触发示范
阶段 B  三轮示范 → 摆放（主线，必做）
  ↓   ┐
  ↓   ├ 期间任何时候可以显影、拾取碎片、做二合（支线，可不做）
  ↓   ┘
阶段 C  三件全部摆对 → 隐藏隔间打开 → 拿 47 号钥匙 → 出口解锁
  ↓
开门：所有镜中倒影同时慢半拍 → 淡出 → 单元二
```

### 2.3 主线谜题：示范与摆放

**核心规则**：白面具哑剧演员只出现在镜子里，面朝玩家示范。她把玩具放在「**她自己的**」左或右边。玩家必须按**她的**左右摆，不能按自己看到的屏幕左右摆。

演员面朝玩家，所以她的左边 = 玩家的右边。平台编号从玩家视角 0 / 1 / 2（左中右），正确平台 = `2 - 演员看起来放的位置`：

| 轮次 | 出现在 | 演员拿起 | 在玩家看来放到 | 正确答案 | 设计意图 |
|---|---|---|---|---|---|
| 1 | 中央镜 M1 | 布偶兔 T1 | 中间 P1 | **P1** | 中间不受左右影响，先教「看她示范、照着摆」 |
| 2 | 左镜 M0 | 发条木马 T0 | 左边 P0 | **P2** | 第一次左右陷阱 |
| 3 | 右镜 M2 | 铁皮小鼓 T2 | 右边 P2 | **P0** | 确认规则 |

**【建议】** 示范顺序固定，不随机，保证每个玩家的体验和视频一致。

**单轮流程**

1. 演员在指定镜中出现（淡入），从镜中的玩具堆里拿起对应玩具（镜中世界有一套只在镜里可见的玩具和平台）。
2. 把玩具放到镜中的某个平台上，然后**左手食指在镜面上点两下**（暗号，全片第一次）。
3. 演员从这面镜子淡出，玩家去现实房间拿起对应玩具（`FirstPersonPlayer.Hand`），放到平台上。
4. 判定：
   - **放对**：玩具落稳，镜中那件玩具同时消失；轻微玻璃共鸣；演员在下一面镜中出现，开始下一轮。
   - **放错**：玩具在平台上停 0.5 秒后缓缓滑回原位（不是弹飞），所有镜面泛起一圈轻微波纹，**本轮重新示范**。不扣任何东西、不出现文字。
   - **拿错玩具**：放不上平台，玩具从手里轻轻落回原位。
5. 已经放对的轮次不会因为后面放错而重置。

剧本里的「CHOICE：按玩家左右 / 按演员自身左右」**不做成菜单**，就是这一步的摆放动作本身。

**无文字提示阶梯**（替代 HUD 的 H 键文字提示，同一轮连续放错时逐级出现）

| 放错次数 | 演员的提示动作 |
|---|---|
| 1 | 重新示范，放下后在镜面点两下 |
| 2 | 示范前先抬起**左手**，白手套在镜中微微发亮，再用左手放玩具 |
| 3 | 正确的那个现实平台边缘在**镜子里**亮一下（现实里看不见，只在镜中可见） |

**信任值**：**【待定】** 剧本说 CHOICE 里「按表演者暗示做」+1，建议在这里算一次：第 2、3 轮都**一次放对**（没用到第 3 级提示），记 `trust.u1_follow`。

### 2.4 镜中倒影慢半拍（F3）

- 现有 `MirrorBody` 让一个只在镜中可见的身体跟随玩家。**【建议】** 新增「延迟跟随」：记录玩家最近约 0.4 秒的位置和朝向，镜中身体播放 0.4 秒前的姿态。比缓存整帧镜面画面省很多显存。
- 默认延迟 0.25 秒（微妙，不一定察觉）；出口开门那一刻，所有镜中身体同时拉到 0.6 秒，再慢慢恢复（1-6「所有倒影同时慢半拍」）。
- 镜中身体外观 = @R1（米白旧演出服的孩子），只在镜子里看得到，所以玩家看到的「自己」是梦里能上台的那个孩子。

### 2.5 显影系统（全片通用，在单元一首次出现）

**操作**：屏幕右下角一个相机图标（无文字），按 **Q** 或点图标。**【建议】** 每按一次依次切换：梦界 → 被拐前（暖）→ 被拐后（冷）→ 梦界。图标下方三个小点表示当前层，同样无文字。

**每次切换**：

1. 播放一次轻快门声，画面白闪 0.15 秒。
2. 切换全屏调色（梦界 / 暖 / 冷）。
3. 切换本层专属物件的显隐。
4. 切换手风琴的处理方式（见 2.9）。

**【待定】** 剧本没写玩家怎么知道有显影。**【建议】** 第一轮示范结束后，相机图标第一次出现，伴随一次远处的快门声（和序章第 16 秒同一种），图标轻微呼吸闪烁，直到玩家第一次按下。不加文字说明。

**单元一的三个显影坐标**

| 坐标 | 梦界 | 被拐前（暖） | 被拐后（冷） |
|---|---|---|---|
| 中央镜 M1 镜面 | 正常反射，倒影慢半拍 | 镜面变成视频 **1-3**（庙会彩灯 + 牵着的手），循环播放 | 镜面变成视频 **1-4**（后台储物箱 + 白面具内侧两道划痕），循环播放 |
| 地面左下（M0 与 P0 之间） | 一件小玩具的影子 | **半张撕毁的票根**（3D 物件，可拾取） | 地上两道划痕的反光 |
| 右侧墙边 | 空的装饰平台 | 墙上彩灯光斑（暖色光投影） | 菱格纹袖口从门缝一掠而过，**铃铛不响**（循环，间隔 8–12 秒，F4） |

- 中央镜在暖 / 冷层不再做实时反射，而是把视频贴到镜面上（`VideoPlayer` 输出到贴图）。镜框不变，所以构图和梦界一致。
- 显影时**演员示范暂停**，回到梦界后继续，避免玩家在暖 / 冷层错过示范。
- 主线谜题只在梦界进行：暖 / 冷层中玩具和平台仍在，但不能拿起。

### 2.6 记忆碎片与相簿

| 碎片 | 所在层 | 拾取方式 | 相簿标题 | 前 / 后 |
|---|---|---|---|---|
| 半张票根 | 被拐前（暖） | 准星对准地面左下的票根，按 E | 半张票根 | 前 |

拾取表现：物件飞向屏幕右下相机图标并缩小消失，播放 `Pickup` 音效。

**不对的细节**（EXPLORE，无文字）：三面主镜、三件玩具、三个平台、守则、镜框边缘的划痕。准星对准按 E → 镜头缓慢推近 1.5 秒看特写 → 收进相簿「观察」页（只有缩略图，没有标题和解释）。

**相簿界面**（按 Tab 打开，`InputGate.Hold()`）：

- 右页「观察」：缩略图。
- 底部两个空槽（二合），无文字。

### 2.7 二合解谜

- 把「半张票根（前）」和「两道划痕（后）」分别拖进两个槽 → **成功**：
  1. 关闭相簿，全屏播放视频 **1-5**（6 秒，病房床沿，大人的手点两下）。
  2. 守则第一条「不许说话」旁多一道指甲划痕。
  3. 记录 `combo.u1` 和 `trust.combo_u1`。
  4. 两件碎片在相簿里变成合并后的一张图，不能再拖。
- 槽里放了两件不配对的碎片（单元一内只有两件，之后单元会出现跨单元误配）→ 两件轻轻弹回原位，无文字、无错误音（只有一声很轻的纸张声）。
- 二合**不是过关必需**，但 E3 需要五组全部完成。

### 2.8 《表演守则》

- 墙上一张旧纸，准星对准按 E 打开全屏阅读，再按 E 或 Esc 关闭。
- 纸面五条守则为 UI 文字（支持中英文），各种划痕、涂改、缝线是叠在对应行上的图片，按进度显示：

| 状态 | 来源 | 表现 |
|---|---|---|
| 初始 | — | 五条守则，打印体，干净 |
| `combo.u1` | 单元一二合 | 第一条旁一道细长指甲划痕 |
| `combo.u2` | 单元二 | 第二条被红笔用力涂改 |
| `combo.u3` | 单元三 | 第三条被彩线一针针绣掉 |
| `combo.u4` | 单元四 | 第五条被三种笔迹划掉 |
| 终章 | 终极二合 | 第三条三色划痕 + 蜡笔小字「叫」「大声叫」「叫妈妈」 |

后续每个单元入口都挂同一张纸，读同一份进度。

### 2.9 声音

| 层 | 手风琴三拍子 | 环境 |
|---|---|---|
| 梦界 | 隔壁房间感：低通约 1.5 kHz + 大混响，音量 60% | 玻璃轻微共鸣 |
| 被拐前（暖） | 旧录音带：带通 + 磁带底噪 + 轻微走音 | 远处模糊人声（不成句） |
| 被拐后（冷） | 同上，底噪更重、音量 35%、更远 | 无人声 |
| 1-5 短片 | 视频自带：空调、心电滴声、呼吸，手风琴只剩最远两个音 | — |

**【建议】** 用 AudioMixer 的四个快照切换（交叉淡入 0.3 秒），一条手风琴音源就够；手风琴音源用现有 `bgm_mirror_room.mp3` 先占位。

### 2.10 演员（白面具哑剧演员 @R3）

### 2.11 过关（1-6）

1. 第三件玩具放对 → 0.8 秒停顿 → P1 平台下方隐藏隔间伴随机械轻响打开。
